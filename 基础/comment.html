基本用法

一个基本的评论组件，带有作者、头像、时间和操作。

对齐

通过 align 属性可以设置 datetime 和 actions 的对齐方式.

评论可以嵌套使用

参数名 描述 类型 默认值

avatar 头像 string -
content 评论内容 string -
datetime 时间描述 string -
align 靠左/靠右 展示 datetime 和 actions 'left' | 'right' | { datetime?: "left" | "right"; actions?: "left" | "right" } 'left'
