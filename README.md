# 基础组件 Demo

双击根目录的 `index.html` 即可打开，浏览时无需启动服务。

| 目录 | 编辑内容 |
| --- | --- |
| 基础 | 每个组件的 HTML 文档及 Demo，另有指南和更新日志 |
| 基础组件 | 每个组件的 JavaScript 入口 |
| 图片 | 页面与 Demo 使用的本地图片 |
| 字体 | 本地字体文件与授权 |
| 变量css | 配色、主题等 CSS 变量 |
| 样式css | 页面、组件与 Demo 的普通样式 |

修改后，在 PowerShell 进入隐藏的 `.维护` 目录，然后执行 `npm run update` 刷新双击版。初次维护需要 Node.js 22 和 `npm ci`。三个以「站点」开头的 JS 和 CSS 文件由这条命令生成。需要实时预览时，在 `.维护` 执行 `npm run dev`。

组件实现来自 Arco Vue 2.59.0。需要远程接口的 Demo 仍需联网。
